# Database

- `voting_system.sql`: export of the database (tables and demo data). Export it from
  phpMyAdmin: select the `voting_system` database, click **Export**, then **Export**.
- `voters_dataset.csv`: the sample voter register (1,000 rows) used for identity
  verification. All names and IC numbers are synthetic test data. The IC numbers are
  9 digits, so they are not valid Malaysian MyKad numbers.
